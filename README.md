# hrdotcom-working

## Task app preview

Run `npm run dev` from the repository root. No dependency installation is needed;
the server uses Node.js built-in modules. It listens on `0.0.0.0` and uses `PORT`
when provided (default: `3000`).

The preview root `/`, `/test-2.html`, and `/test/test-2.html` all serve the single-file
HTML/CSS/JavaScript app in `test/test-2.html`. Other workspace files are not served.

Workspace preview: https://preview-ws-77f4c622.aq.dev/
