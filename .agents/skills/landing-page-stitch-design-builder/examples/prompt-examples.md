# Prompt Examples for Stitch

These examples demonstrate the correct format and detail required when sending text prompts to the Stitch MCP server.

## SaaS Landing Page Prompt
"Create a modern SaaS landing page. Include a large, full-width hero section with a bold primary heading, a supporting paragraph, and two CTA buttons (primary and secondary). Below the hero, add a 3-column feature grid using card styling, generous padding, and subtle borders. Finish with a dark-themed footer. Use spacious layout, clear typography hierarchy, and clean modern styling aligned with our dark/white contrast motif guidelines."

## Dashboard Prompt
"Design a user analytics dashboard. Include a left-aligned sidebar with navigation links and active state highlighting using brand primary colors. The main content area should feature a top row of four KPI metric cards (Total Users, Revenue, Active Sessions, Bounce Rate). Below the metrics, include a large central data chart area and a recent activity table on the right. Maintain high contrast for readability and minimal visual clutter."

## Signup Flow Prompt
"Create a clean, distraction-free signup screen. The layout should be a centered, narrow card on a light background. Inside the card, include the company logo at the top (aligned with brand-guidelines padding), a clear 'Create your account' heading, input fields for Email and Password with inline labels, and a full-width primary CTA button. Include a subtle 'Already have an account? Log in' link below the button."

## Marketing Page Prompt
"Build an engaging product marketing page. Start with an impactful hero image overlaid with a strong value proposition and call to action. Use a modular section approach, alternating left/right image and text blocks. Include a prominent 'Trusted By' logo strip. Apply generous whitespace, large readable typography, and modern UI accents."
