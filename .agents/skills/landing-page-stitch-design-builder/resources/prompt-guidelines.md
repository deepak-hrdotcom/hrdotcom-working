# Stitch Prompt Guidelines

When generating prompts for the Stitch MCP server, adhere to the following guidelines to ensure optimal output.

## Essential Elements

Each prompt should contain:
1. **Page Purpose**: Clearly state what the screen is for (e.g., "SaaS landing page", "User dashboard").
2. **Layout Structure**: Describe the high-level layout (e.g., "Hero section at the top, followed by a 3-column feature grid").
3. **Key UI Components**: List the main elements (e.g., "Primary CTA button, secondary navigation, metric cards").
4. **Hierarchy of Sections**: Order the content logically.
5. **Tone of Visual Design**: Reference brand feel (e.g., "Clean, modern, highly readable").

## Style and Tone

- Use declarative, precise language.
- Avoid vague terms like "make it look nice". Instead, use "use generous whitespace and a clear typography hierarchy".
- Reference brand guidelines for specific color, spacing, and typography constraints.
