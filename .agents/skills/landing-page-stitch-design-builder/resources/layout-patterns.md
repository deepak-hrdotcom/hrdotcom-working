# Layout Patterns

These layout patterns should inform the structures you request from Stitch to ensure modern, clean UI principles.

## Landing Pages
- **Hero**: Full-width, prominent headline, text block, primary Call-To-Action (CTA).
- **Features**: 3 or 4 column grid of cards with icons, titles, and short text.
- **Testimonials / Social Proof**: Centered carousel or grid, high contrast.
- **Footer**: Multi-column links, logo, copyright.

## Dashboards
- **Sidebar Navigation**: Left-aligned, dark or distinct background, active states visible.
- **Top Bar**: Search, user profile, notifications.
- **Main Content Area**: Card-based widgets, data tables, metrics (KPIs) presented in a grid.

## Forms / Signup Flows
- **Centered Layout**: Single column, narrow width, clean background.
- **Progressive Disclosure**: Break complex forms into manageable steps.
- **Clear Actions**: Prominent primary button, subtle secondary links.
