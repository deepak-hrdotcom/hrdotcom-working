# Trigger Phrases

The following phrases should trigger the orchestrating-project-starts skill:

## General Projects
- start a new conversation
- start a new project
- let’s do section by section
- create a new page
- let’s create this page

## Landing / Web Pages
- begin a new splash page
- create a marketing page
- create a research page
- create an event page
- promotional page
- start section 1
- begin section 1
- here is the first section
- here is the first section content
- let’s build this page

## Emailers
- create a new emailer
- build an email campaign
- generate a responsive email template
